Built like a dependable data product, not a one-off script.

The project deliberately connects ingestion, validation, warehousing, transformation, and human review into one traceable delivery path.

01

Immutable ingestion

CSV, JSON Lines, Excel, and paginated REST inputs land in partitioned bronze Parquet with checksums and watermarks.

02

Quality gates

Schema, uniqueness, null, numeric-bound, and relationship checks produce structured reports and row-level quarantine files.

03

Human-in-the-loop audit

Category suggestions are validated, cached, and held for review; untrusted model output never changes the source blindly.
